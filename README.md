# Stroke

Stroke คือโครงการพัฒนาเว็บแอปพลิเคชัน

## สถานะโครงการ

โครงการอยู่ระหว่างการตั้งค่า รายละเอียดความต้องการและการพัฒนาจะถูกเพิ่มเมื่อมีเอกสารสรุปความต้องการของโครงการ

## การอัปเดตโครงการ

อัปเดตไฟล์นี้ทุกครั้งที่แอปพลิเคชันมีการเปลี่ยนแปลง โดยระบุขั้นตอนการตั้งค่า ฟีเจอร์ การกำหนดค่า และการตัดสินใจสำคัญ
